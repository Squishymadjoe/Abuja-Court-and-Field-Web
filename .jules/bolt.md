## 2025-02-28 - [Stabilizing Manual Router Switch State with Same Element Reference]
**Learning:** In React, updating a parent component state (e.g. playing/pausing an audio player) causes the parent to re-render. If the parent does a manual switch-case to select the current page component, that switch-case will run on every render and construct new React elements. This forces the entire active page component tree to completely re-render, even if the active page's props did not change. By stabilizing any callbacks passed to the child pages with `useCallback`, and memoizing the switch-case output with `useMemo`, we preserve the exact same React element reference. This leverages React's 'referential equality bail-out' to completely block unnecessary child page tree re-renders without having to wrap each individual child component with `React.memo`.
**Action:** Use `useCallback` to stabilize all callback handlers and `useMemo` to memoize the manual routing switch-case logic in the parent component.
