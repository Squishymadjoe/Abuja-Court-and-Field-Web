## 2026-05-18 - The Triple-Sync Optimization for SPA Re-renders
**Learning:** In a manual routing SPA architecture (using `switch` statements), a single `React.memo` on child components is often insufficient to prevent re-renders. A "render leak" occurs because the routing logic in the parent re-instantiates the entire page component on every parent render. To truly stop unnecessary re-renders, a three-part synchronization is required: 1) Stabilize parent callbacks with `useCallback`, 2) Stabilize the page instance with `useMemo` in the router, and 3) Wrap leaf components in `React.memo`.
**Action:** When optimizing list items in an SPA, always trace the render path up to the router. If a `switch` statement is used for navigation, wrap its result in `useMemo` to ensure component identity is preserved across parent state changes.
