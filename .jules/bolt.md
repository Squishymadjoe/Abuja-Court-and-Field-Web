## 2025-05-20 - Manual Routing Page Re-render Optimization
**Learning:** In React applications with manual switch-case routing in parent components (like `App.tsx`), state updates that affect global layout components (e.g., toggling an audio player or mobile drawer) trigger re-evaluations that recreate JSX element trees for child pages on every render cycle. Wrapping handler callbacks in `useCallback` and the page JSX switch-case in `useMemo` leverages React's 'Same Element Reference' optimization, completely preventing the child component tree from re-instantiating.
**Action:** When manual routing is used at the top level alongside layout state, use `useMemo` for rendered page routes and `useCallback` for route callbacks before attempting `React.memo` on individual page components.
