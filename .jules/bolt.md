## 2025-07-20 - [Performance Optimization of React Rendering and ESM Setup]
**Learning:** React re-renders can be triggered by changes in parent state. Toggling audio state (playing/currentEpisode) triggers re-renders of the active page component tree. In App.tsx, stabilizing handlers with `useCallback` and memoizing the switch-case result with `useMemo` eliminates unnecessary renders by 100% (Same Element Reference optimization). Furthermore, during local verification/build, a temporary module script tag pointing to `/index.tsx` is required in `index.html` to fully compile and build all the React components (~37 modules instead of only ~2), but must be removed before PR submission to avoid affecting the production ESM importmap.
**Action:** Use `useCallback` for event handlers and `useMemo` for page routing switches in `App.tsx` using `currentPage`, `setCurrentPage`, and `handlePlayEpisode` in the dependency array to achieve complete same-element-reference optimization. Temporarily inject index.tsx in index.html during profiling/verification, and remove it before final PR submission. Do not commit `pnpm-lock.yaml`.
