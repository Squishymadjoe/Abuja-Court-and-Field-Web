## 2025-03-09 - [Manual Routing Render Leaks]
**Learning:** In React applications with a global/top-level layout containing frequently updated state (e.g., an audio player with playback state), manual routing with switch-case components inside the parent functional component can cause complete page re-renders on every state transition. Standard children optimization (or passing stabilized callbacks/refs) alone is insufficient if the page tree is fully rebuilt on every render.
**Action:** Use `useMemo` to cache the manual routing page render switch-case tree and couple it with `useCallback` for event handlers passed down to the child page components. This leverages React's Same Element Reference optimization, completely bailing out of child component re-renders unless the routing dependencies (e.g., currentPage) change.
