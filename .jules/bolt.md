## 2025-07-31 - [Manual Routing Switch-Case Render Leak Fix]
**Learning:** In React applications featuring stateful layout or global components (like a persistent Audio Player), updates to global player states (e.g. `isPlaying`, `currentEpisode`) trigger component-wide re-renders of the root/layout component. If manual routing switch-case page elements are re-instantiated in-place during these re-renders, the entire current page component tree re-renders unnecessarily.
**Action:** Wrap the manual routing switch-case block with `useMemo` depending only on page-reactive props, and stabilize any passed actions (like `handlePlayEpisode`) with `useCallback`. This leverages React's "Same Element Reference" optimization to stop the current page rendering pipeline entirely when the parent's audio player states update.
