## 2025-05-18 - Prevent Routing Render Leaks from Global Player State
**Learning:** In manual routing setups where `App.tsx` conditionally renders page components inside a switch statement, state updates in `App` (such as `isPlaying` or `currentEpisode` for a global sticky player) re-execute the switch and instantiate brand new React JSX elements on every render. This forces the entire active page view and all child components to re-render from scratch even if their props haven't changed.
**Action:** Wrap event handler callbacks (`handlePlayEpisode`) with `useCallback` and memoize the rendered page JSX tree with `useMemo` (`[currentPage, setCurrentPage, handlePlayEpisode]`). This leverages React's Same Element Reference optimization to bail out of re-rendering active page components during player state changes.
