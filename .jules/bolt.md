## 2026-07-24 - [Manual Page Routing Same Element Reference Optimization]
**Learning:** In a single-page manual routing application (e.g. using a switch-case `renderPage` function), state updates in the parent component (such as toggling an audio player's play/pause state) trigger full component tree updates for whatever page is currently selected. Using `useMemo` on the rendered page elements, alongside `useCallback` on event handlers passed to them, activates React's "Same Element Reference" bailout optimization, completely bypassing unnecessary rendering of the child page components when independent parent state toggles.
**Action:** Always wrap manual routing switch-cases or page renders in a `useMemo` block, and ensure all event handlers passed to them are stabilized with `useCallback` to prevent reference-change updates.
