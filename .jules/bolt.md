## 2025-03-08 - [React manual routing same-element-reference render leaks]
**Learning:** In a single-page application structure utilizing a manual routing switch statement in a top-level parent (such as `App.tsx`), any state updates within that parent (e.g., toggling play/pause audio player controls or changing current episode) will trigger complete re-renders of the currently rendered child page component. By enforcing callback stability on event handlers passed to the child pages (with `useCallback`) and memoizing the switch-case manual routing logic (with `useMemo` of the rendered element tree), combined with `React.memo` wrapping on child page components, we achieve a 100% reduction in unnecessary page re-renders. This utilizes React's Same Element Reference optimization effectively.
**Action:** Always pair stable parent-state callback handlers (`useCallback`) with memoized route rendering trees (`useMemo`) and `React.memo` on child components when dealing with manual custom routing components in React.
