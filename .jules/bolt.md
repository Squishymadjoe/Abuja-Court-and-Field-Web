## 2026-04-18 - [React Render Optimization in Global Layout]
**Learning:** In an SPA where the main page is rendered as a child of a Layout that also contains global state (like an audio player), updating the global state (e.g., `isPlaying`) causes the entire `App` component to re-render. This triggers a re-render of the currently active page component, even if its props haven't changed, because it's usually returned from a function like `renderPage()`. Stabilizing the page instance with `useMemo` and parent callbacks with `useCallback`, combined with `React.memo` on list items, is necessary to achieve zero re-renders of the list during global state updates.
**Action:** Always check if the router or page-rendering logic in `App` is memoized when optimizing list re-renders triggered by global state.
