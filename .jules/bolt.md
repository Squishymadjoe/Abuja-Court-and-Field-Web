## 2025-02-28 - App-Level Page Memoization Prevents Player-State Re-Render Leaks
**Learning:** In top-level router components that pass global state (like audio player state) down to Layout alongside page components, state updates (e.g. toggling play/pause or current episode) cause `App` to re-render. Re-evaluating inline switch-case JSX renders new element references every time, forcing the entire active page tree to re-render even if child component props didn't change. Memoizing the page switch statement with `useMemo` and stabilizing trigger callbacks with `useCallback` enables React's "Same Element Reference" bailout, reducing page re-renders by 100% during player interactions without needing `React.memo` on every child page/component.
**Action:** Always memoize manual switch-case page routing elements in top-level state container components when global UI overlay state (audio player, modal, notifications) frequently updates.
