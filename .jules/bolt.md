## 2025-03-05 - Manual Routing Same Element Reference Optimization
**Learning:** In App.tsx, global states such as audio player status (`isPlaying`, `currentEpisode`) cause the entire `App` component tree to re-render. This triggers cascading re-renders across any currently active page component (e.g. `Home`, `Episodes`), even if those page components do not consume any audio state. By stabilizing page transition and event handler callbacks with `useCallback` and wrapping the manual routing `switch-case` in `useMemo` (Same Element Reference optimization), we completely eliminate unnecessary renders of the page components when the player is toggled, avoiding deep tree re-evaluations.
**Action:** In manual routing designs, always decouple audio/video player playback states from the layout-level page switches by memoizing the rendered page element tree and ensuring its dependency array only contains page-specific parameters.
